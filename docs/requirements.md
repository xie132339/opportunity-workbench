# 当前需求与验收范围

> 本页受 [当前产品契约](current-product-contract.md) 约束。此前的多平台、个人交易和历史方案已归档，不构成现行需求。

## R1：官方优惠发现

- 系统只从已启用且健康的第一方来源写入默认优惠列表。
- 淘宝当前使用 `taobao.tbk.dg.material.optional.upgrade`；来源必须保存官方商品身份、官方推广入口、采集时间与原始字段。每轮按 100 条自动翻页，直到官方返回不足一页；重复页或 1000 页安全上限必须留下扫描回执。
- 缺商品身份、链接、正数价格或当前优惠信号的记录，不得进入默认列表。

**验收：** 实时扫描回执与 `source_scan_runs` 的页数、解析数、优惠数、拒收数可对应；每条默认记录都能从详情进入官方推广路径；无优惠信号的商品价只能处于审计状态。

## R2：价格与优惠口径

- 默认显示可解释的官方推广价；条件券价需要门槛、金额、有效期和适用数量齐全。
- 不解释的预估价、空金额和商品目录标价只能留在审计，不得作为默认报价。
- SKU 详情不可用不能隐藏符合 R1 的官方优惠观察。

**验收：** 官方物料在详情受限时仍显示“淘宝联盟官方推广价”；页面不出现把未知金额当报价的“金额未提取”或“金额口径待确认”。

## R3：捡漏判定

- 捡漏判断是可选的本地校准，不是官方优惠观察的准入条件。只有官方推广价唯一命中运营人员维护的品牌、商品、规格、单位和价格带时，才显示“按维护基准：可捡漏/优惠/低于常规/常规价格/价格偏高”。
- 没有维护基准、规格或单位不明确、规则冲突或价格无效时，保留该条官方优惠观察并正常显示，不显示任何维护基准结论；不得为了补全结论去猜测商品、券、价格或市场价。
- 本期不使用第三方市场价、转载帖或历史交易记录作为基准，因此“按维护基准：可捡漏”只表示低于当前版本的本地固定阈值，不表示全网最低价、账号结算价或转售利润。

**验收：** 未维护基准的官方优惠继续出现在默认列表且不显示“按维护基准”标签；满足全部本地规则字段的测试样例才能显示相应标签；任一不完整或冲突样例不能升级为捡漏结论。

## R4：运行与可追溯性

- worker 按来源配置的间隔扫描；来源 #44 当前为 60 分钟。
- 页面和来源审计展示最近扫描结果与失败原因，不能由旧日志或历史说明替代当前状态。
- 密钥只保存在本机 `.env`，不得写入 Git、来源 URL、页面或文档。

**验收：** 重启后的运行进程可以完成健康检查、扫描和页面回放；敏感配置不出现在版本控制差异中。
