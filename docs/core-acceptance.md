## 2026-10-12 数据驱动校准替换写死阈值（AC-02 自适应收尾）

- 背景：用户明确要求"假优惠判断不能写死、要用不错的算法"。固定阈值（85%/20 倍/10 元-50 元/主题上界）存在两类系统性问题：①低价箱被假货污染、部分 85–90% 假优惠漏网；②高价箱尖刺导致高端真品（康泽泉低氘水 358 元 61%、山茶油礼盒 1498 元）被误拦。
- 算法（`services/discount_calibration.py`，判定边界全部由真实语料统计估计，随数据漂移每小时自动重算）：
  1. **荒谬单价上界**：推广价 `median(log10 cents) + 6×MAD(log10 cents)`（六主题落盘：油 ¥2555 / 洗衣液 ¥646 / 大米 ¥1142 / 纸 ¥356 / 水 ¥457 / 面粉 ¥489）；
