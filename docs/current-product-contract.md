# 当前产品契约：淘宝官方优惠与维护价格基准

> **唯一现行产品规则**｜版本：2026-10-12｜状态：淘宝联盟官方优惠观察已运行；节日专区展示官方组合路径和单券条件试算；本地维护价格带已接入，实际覆盖取决于运营人员录入的具体商品基准。
>
> 其他根目录文档只解释本契约；`docs/history/` 只保留审计材料，不能改变本页结论。

## 1. 目标与范围

工作台从**淘宝联盟第一方物料**持续发现可追溯的优惠商品。平台再将官方推广价与**本工作台内维护的具体商品价格带**比较，帮助发现符合已维护标准的低价。

本期不从第三方价格平台、转载帖、历史交易记录或模型推断生成价格基准。每套价格带由运营人员按品牌、商品、规格、计价单位、生效日期和四个阈值直接维护。维护价格带是展示层的可选校准，不参与官方优惠观察的列表准入：没有维护规则、规格无法换算或规则冲突的商品仍正常展示，但不产生优惠或可捡漏判断。

来源之间的同款归并比较同样不是官方优惠展示或维护价格带的前置条件。结果量较大时，默认优惠、当前线索和历史浏览跳过这项附加诊断，避免它阻断正常列表；“同口径比较”视图始终执行。结果较小时，普通浏览可以显示该诊断，但不会影响商品是否展示。

现有大类不能归档新商品时，可在“价格基准 → 新增品类”添加主题和归类关键词；新增品类不改采集代码。具体品牌、规格、单位和价格仍必须单独建立维护基准。

“价格基准 → 当前官方优惠中的维护候选”只帮助运营从当前官方观察选择维护对象：候选必须有明确官方降幅或可安全复算的单券试算，且标题中有数量或容量单位。候选可创建一个**未保存草稿**，只带入标题、唯一匹配品类和官方证据说明；系统不从候选猜测标题必要词、规格单位或四档金额。候选没有匹配叶子品类时，页面明确要求先配置品类，不能默认选取第一项。

当前已启用并已实测的发现来源：

- API：`taobao.tbk.dg.material.optional.upgrade`。
- 首批生活品主题：纸品（`抽纸`）、饮用水、大米、面粉、食用油、洗衣液。每个主题是一条独立淘宝联盟来源，可单独启停、设定频率、查看最后成功时间和扫描回执。
- 当前主题可在“渠道管理 → 淘宝生活品主题配置”继续增补，例如垃圾袋、洗洁精、卫生巾；不需要为新主题改采集代码。

淘宝是当前试运行渠道。后续接入任何渠道，仍须先满足官方/可审计来源、明确商品身份、正数价格和当前优惠信号的准入条件。

## 2. 数据状态与准入

| 状态 | 必要事实 | 页面可见性 | 不能声称 |
|---|---|---|---|
| 原始候选 | API 返回原始物料，但身份、链接、正数价格或当前优惠信号有缺失 | 仅来源审计 | 不能进入默认优惠列表 |
| **官方优惠观察** | 官方商品身份、官方推广入口、当前采集快照、正数联盟推广价，且有**可解释的当前优惠信号**（参考价差必须通过划线价合理性校验，或当前有效券、当前活动路径之一） | 默认列表和详情可见 | 不能称为账号到手价、全网最低价 |
| **维护基准已判定** | 官方优惠观察命中启用且已生效的本地基准；标题必要词、品类词和规格/单位换算均唯一明确 | 列表排序和详情展示判定 | 只能称“按维护基准”，不能称全网最低价 |
| 维护基准未判定 | 没有规则、规则未生效、必要词不全、单位无法换算或多规则冲突 | 保持官方优惠观察 | 不得猜测优惠级别或捡漏 |

**SKU 详情是增强证据，不是官方优惠展示的阻断条件。** SKU 详情缺失时，满足官方物料条件的商品仍可展示；本地维护基准只会使用标题中明确且可换算的规格，不能把不明确的变体当成已绑定 SKU。

## 3. 价格与优惠条件

1. 默认显示官方返回的联盟推广价 `zk_final_price`，标签为“淘宝联盟官方推广价”。
2. 券后单件试算只在券金额、门槛、有效期和适用数量都可由同一响应复算时展示，且必须标为“条件价”。
3. `final_promotion_price` 只有在当前价格路径可逐项复算时才展示；无法解释的预估金额只留审计字段，不参与展示、排序或结论。
4. 没有有效正数价格的记录只能留在来源审计或被拒收，默认列表不能用“金额未提取”或“金额口径待确认”伪装成报价。
5. 每条官方优惠观察必须可回到官方推广入口；不能指向官方商品或推广路径的记录不得升级。
6. **参考价差合理性（数据驱动校准，2026-10-12 起自适应）**：`reserve_price` 是商家自设的划线价，可任意虚高。参考价差作为官方优惠额前必须先通过合理性校验；判定边界**由 `services/discount_calibration` 从存量语料统计估计，随数据漂移自动更新**，不再手写固定阈值：
   - **荒谬单价上界**：推广价超过主题校准上界（`median(log10 推广价) + 6×MAD(log10 推广价)`，如油主题约 ¥2555、洗衣液约 ¥646、大米约 ¥1142）视为荒谬高价（几千元洗衣液组合、大米关键词误命中的工业设备），仅保留来源审计，不进入默认列表；
   - **降幅与优惠额分箱上界**：按推广价所在价格箱（0.5 个 log10 宽）估计可信降幅 P97 与可信优惠额 P97（校准样本剔除降幅 > 0.92 的明显虚高尾段，防止假货污染估计）；降幅或优惠额任一超过所在箱上界视为划线虚高；
   - **高价豁免**：推广价达到主题 P97 所在箱上界（如食用油 ¥1000、纸品 ¥100、大米 ¥316）以上的记录只受荒谬单价上界与主题全局降幅界约束，不按分箱降幅/优惠额拦截，避免误伤高端真品（康泽泉低氘水 358 元、山茶油礼盒）；**全局降幅界**：豁免区内降幅超过主题全局可信上界（全局 P97，如大米约 82%）仍视为 90%+ 划线虚高并拦截（拦下"科颜氏大米洗发露"93% 划线虚高，保留低氘水 61%、山茶油 55-68% 深折扣）；
   - **品类词过滤（2026-10-12 新增）**：生活品关键词会误命中**非本品类商品**（大米主题混入"科颜氏大米小麦洗发露"优惠 ¥5601、"Reiss 米色条纹服饰"优惠 ¥828，霸占优惠额排序第一名）。`services/discount_calibration::category_matches(topic,title)` 用主题品类词表（include 强词 + exclude/通用干扰词）校验标题：**管理主题需命中品类强词且不含干扰词才产生参考价差优惠额**；不命中时该商品仍以官方推广价保留在默认列表（保真优先），但不产生优惠额、不参与优惠额排序。未知主题、空标题不设品类门槛，避免误伤自定义来源。品类词表是维护性词典，随主题关键词同步维护，非业务阈值；
   - **校准缺失或主题样本不足时回退保守种子**（85%、20 倍、10 元/50 元），首轮校准后即由数据接管；校准快照存 `discount_calibration` 表，worker 每 60 分钟按数据新鲜度重算。
   - **保真优先（不误伤真实捡漏）**：划线价差被判定不可信的商品**仍以官方推广价保留在默认列表**——存在参考价差本身即准入信号（真实便宜货的推广价是可信成交价），但**不产生优惠额、不参与优惠额排序、不显示虚高"优惠 X 元"**，snippet 注明"参考价过高，未据此认定优惠"；只有荒谬单价（推广价超上界）才从默认列表移除。真实可信的优惠（含 5-8 折深折扣）优惠额展示与排序不受影响。
7. **生活品主题荒谬单价拦截（校准上界，2026-10-12 起自适应）**：推广价超过主题校准上界（见规则 6）的物料保留来源审计，不进入默认优惠列表；自定义来源不受上界约束。

## 4. 维护价格带规则

一条价格基准对应一个具体商品口径，字段如下：

| 字段 | 规则 |
|---|---|
| 所属品类 | 归档与标题品类词校验；不能跨主题命中 |
| 基准名称 | 给运营人员识别的具体品牌/商品/型号名称，同品类内唯一 |
| 标题必要词 | 2–12 个品牌、品名、型号或规格必要词，必须全部命中；标题相似不算命中 |
| 计价方式 | 按抽、卷、片、个、包、瓶、克、毫升，或固定规格按件 |
| 基准单位 | 例如每 100 抽、每 1 瓶、每 1000 毫升；必须填明确数量 |
| 固定规格 | 仅“按件”使用；规格去除空格和常见乘号后必须完整命中 |
| 四档金额 | `可捡漏阈值 ≤ 常规低位 ≤ 常规中位 ≤ 常规高位`，全部按分保存 |
| 生效、启用和版本 | 生效日未到、停用规则不参与；每次实际修改递增版本并写审计记录 |

判定算法：

```text
官方推广价
  + 标题必要词全部命中
  + 品类关键词命中
  + 标题中存在唯一且明确的数量/包装换算
  -> 归一到维护基准单位（金额以分四舍五入）
  -> ≤ 可捡漏阈值：按维护基准：可捡漏
  -> ≤ 常规低位：按维护基准：优惠
  -> ≤ 常规中位：按维护基准：低于常规
  -> ≤ 常规高位：按维护基准：常规价格
  -> > 常规高位：按维护基准：价格偏高
```

匹配到多个规则、标题出现“多规格/任选/随机”、没有明确数量、非官方推广价或金额无效时，算法停止并返回“未判定/冲突”，不输出等级。

`按维护基准：可捡漏`仅代表该官方推广价低于该版本的本地固定阈值。它不代表账号最终应付、领券资格、运费、库存、全网最低价、独立市场真实价格或转售利润。

## 5. 当前数据流

```text
淘宝联盟官方物料 API
  -> 参数与签名校验
  -> 商品身份和官方入口校验
  -> 价格/优惠路径解释
  -> 原始候选 或 官方优惠观察
  -> 命中本地维护价格带？
       -> 是：单位归一、版本化价格带判定、列表/详情显示
       -> 否：保留官方优惠观察，不下价格带结论
```

worker 每分钟检查到期且启用的淘宝联盟主题；每个主题按自己的频率独立执行。每轮从第 1 页以 100 条请求官方 API，持续翻页到不足 100 条。重复整页、官方结果页数耗尽和 1000 页安全上限都会停止并写入 `source_scan_runs` 回执。采集到多少合格官方物料就入多少原始观察；价格带规则不限制采集量，只影响展示的判断标签。

## 7. 验收结论与下一门槛

实现验收：价格带创建/编辑/停用、非法阈值拒收、版本审计、抽纸多包换算、容量换算、固定规格、规则冲突/缺规格拒判和列表呈现均由自动测试覆盖。

运营验收尚未开始：系统不会编造任一品牌的常规价格。必须由运营人员在“价格基准”页录入真实商品口径和固定价格带，随后用对应淘宝官方优惠回放检查：标题、数量换算、单位价格、基准版本和判定标签是否与维护记录一致。若一次误匹配、错误换算或过期规则仍然产生结论，则收紧必要词、调整规格或停用规则并复测。

账号结算价仍未取得。它不是本期固定价格带的输入，也不影响官方优惠发现；页面必须持续将它与“按维护基准”判断分开说明。

## 8. 文档与变更规则

- 改动基准字段、单位换算、阈值或页面标签时，先更新本页，再更新实现和验收。
- 新增价格带时，必须记录维护说明；价格数字由运营人员负责，不得由程序、模型或第三方转载自动填充。
- 任何当前结论必须带当日测试、数据库版本或官方同步回执；没有依据时写“未验证”。
- `docs/history/` 的内容不得被链接为当前规则。

## 9. 官方活动会场与优惠排序

“官方活动”页面保存两个不能混用的官方字段：`activity_material_id` 只调用 `taobao.tbk.activity.info.get`，用于核验会场名称、时间和官方推广入口；`material_id` 可选，且只调用 `taobao.tbk.dg.material.optional.upgrade` 建立定时商品物料来源。会场 API 返回的活动页不构成商品身份、商品价格、券资格或结算价证据；只填会场 ID 时不得产生商品记录。

默认“公开优惠”按**当次官方可解释优惠额**从高到低排列。每条商品只会从下列路径中选择金额最大的单一路径：推广价相对联盟返回参考价差、可单独复算的单券减免、完整官方促销路径减免。路径不叠加。优惠比例只在该路径有明确分母时计算，作为次级排序；没有可解释优惠额的记录排在最后。此排序用于发现优先级，不代表账号到手价、活动价可用性或全网最低价。

页面提供官方会场链接和可复制的手动推广文本，但系统不发布、不发送或代用户推广。文案必须提示价格、库存、券资格和最终支付金额以淘宝页面或结算页为准。

## 10. 节日大促专区与参与优先级

双11、618、双12、年货节及自定义节日通过独立顶级菜单“节日大促”管理。该菜单只负责官方商品物料发现、归节日、定时采集与参与条件排序；不重复建立或核验活动会场。官方会场继续在独立的“官方活动”菜单维护。节日商品物料由 `material_id` 建立独立定时来源，节日规则和最低优惠额由节日菜单管理；历史上关联会场的节日记录保留只读展示，编辑入口仍归“官方活动”。

如果暂时不知道活动商品物料 ID，可在节日页调用淘宝联盟推广者物料列表发现当前账号可用的商品物料，查看官方名称和有效期后再手动归类。加入监控时会再次向官方接口复核物料仍可见，之后才建立独立的定时商品来源。推广者物料列表只证明账号当前可见该物料，不证明它属于双11；不得按名称相似、日期重叠或历史 ID 自动归节日。节日商品的真实关联必须能追溯到官方公告或运营者确认；无证据时标为待确认/不展示为双11商品。

节日商品按参与条件分层，不能只看券面额：

1. **可直接参与**：联盟物料显示推广价低于官方参考价，或单品券的时间、剩余量和单件门槛均满足，或完整官方促销路径可以复算。仅该层达到运营设置的最低官方优惠额后，按单一可解释优惠额降序、优惠比例次序、参与复杂度排序。
2. **需凑单后再核验**：物料显示的券门槛高于当前单品金额时，展示还差金额和原因，但不进入最优参与榜单，也不把券面额算为本商品已获得优惠。
3. **条件不足**：未返回可复算条件、券已失效或库存/资格不明的物料只计数，不展示成优惠参与建议。

“最优参与”是当前官方物料内的发现排序，不是不同商品之间的同款比价、账号结算承诺或全网最低价。每条参与建议必须保留官方推广入口，并提示用户以淘宝页面、购物车规则和结算页为准。

### 节日优惠组合说明

节日页每件商品只展示该商品官方字段可以证明的省钱办法，不把未知券或个人账户权益算进去：

1. 淘宝联盟[物料搜索 API](https://developer.alibaba.com/docs/api.htm?apiId=64759) 返回完整促销路径，且各项减免之和与接口预估价一致时，逐项列出优惠并显示该路径的条件预估价。

3. 优惠券未达到门槛时显示“还差金额”。只有购物车里本来就要买的商品才考虑凑单，不建议为了领券额外消费。

### 节日购买清单组合计算（2026-10-12）

独立入口 `/festival-promotions#calculator` 支持手动清单，也可按商品详情编号导入当前采集有效的淘宝官方报价和优惠路径。只读取既有商品，不写测试商品或伪造双11归属。

- **输入**：1–8 种商品的当前单价、数量、同店子订单分组及运费；最多 12 条优惠的金额/折扣、门槛、适用商品、最低件数、有效期、封顶和来源链接。未知运费不按零；同子订单运费只能计一次。
- **规则**：同子订单组的店铺优惠互斥；其他重叠优惠须明确允许叠加。完整官方单件路径整体择一，不拆成券再次抵扣。未确认账号资格、适用范围或有效期的优惠不计入结果。
- **2026 超级红包**：按官方已发布规则在券后抵扣；最多 10 个、有门槛最多 1 个，只抵商品货款。每张必须录入实际已领金额、适用商品及独立有效期；不使用宣传最高额。二阶段未公布内容不补猜。来源：[消费者规则](https://1111.alimama.com/alimamamain/page_20211227_144813)。
- **算法**：整数分计算，最多枚举 4096 个优惠子集，验证门槛及冲突后比较含运费总付款。按单品/店铺/平台/红包层级、同层表单顺序计算；跨商品按金额比例分摊、余分按余数分配。不把贪心选择最大单券当最优。
- **结果**：三步说明买什么、选哪些优惠、预计付多少；备选与排除原因折叠。草稿保存在当前浏览器。模拟例子明确标注：2×100，9折与200减10二选一，再抵假设已领5元红包，预计175；若运费6，预计181。

验收：互斥、显式叠加、未知条件、时效、件数、门槛、封顶、运费、余分、重复券、上限、登录和CSRF均须通过；实际页面提交与修改后重新计算须得到相同结果。真实导入须保留采集时间并默认未确认，不产生结算承诺。

“最低预估”只限已输入的固定商品数量、订单分组、规则顺序、分摊方式及固定运费。未实现自动读个人券包、拆单/增购搜索、跨店替代商品搜索或淘宝真实结算核验；不能称全局最低价。平台实际分摊或资格不同会改变结果，必须以结算页复核。
