# 当前产品契约：淘宝官方优惠发现与可证据化捡漏

> **唯一现行产品规则**｜版本：2026-10-11｜状态：淘宝官方优惠观察已运行；同款基准捡漏判定尚未开放。
>
> 其他根目录文档只解释本契约；`docs/history/` 只保留审计材料，不能改变本页结论。

## 1. 目标与范围

工作台先从**淘宝联盟第一方物料**持续发现可追溯的优惠商品，再在证据充分时判断是否低于同款市场基准。默认列表只展示已通过当前准入的淘宝官方优惠观察，不能把商品目录、转载帖、没有优惠信号的原价商品当作优惠。

当前已启用并已实测的来源：

- API：`taobao.tbk.dg.material.optional.upgrade`。
- 首批生活品主题：纸品（`抽纸`）、饮用水、大米、面粉、食用油、洗衣液。每个主题是一条独立的淘宝联盟来源，可单独启停、设定频率、查看最后成功时间和扫描回执；它们不是把多个关键词塞进一条“抽纸”任务。
- 已有 `#44 淘宝店抽纸优惠搜索` 被沿用为纸品主题；其余主题来源 #45—#49 均已启用，检查间隔均为 60 分钟（2026-10-11 数据库快照）。“渠道管理 → 淘宝生活品主题配置”可新增例如垃圾袋、洗洁精、卫生巾等主题，无需改代码或改写旧来源的关键词。
- 每次扫描保存来源、官方商品身份、官方推广入口、原始字段和采集时间；密钥不得写入来源 URL、页面或文档。

淘宝是当前试运行渠道。后续接入任何渠道都必须满足本页同样的来源、身份、价格和优惠条件证据，不能以渠道数量替代准入。

## 2. 数据状态与准入

| 状态 | 必要事实 | 页面可见性 | 不能声称 |
|---|---|---|---|
| 原始候选 | API 返回原始物料，但身份、链接、正数价格或当前优惠信号有缺失 | 仅来源审计 | 不能进入默认优惠列表 |
| **官方优惠观察** | 官方商品身份、官方推广入口、当前采集快照、正数联盟推广价，且有参考价降幅、当前有效券或当前活动路径之一 | 默认列表和详情可见 | 不能称为账号到手价或已证实捡漏 |
| SKU 已绑定优惠观察 | 同一官方商品内返回 SKU、规格、库存和 SKU 价格 | 可用于规格比较准备 | 仍不能省略账号资格或市场基准 |
| 已证实捡漏 | 同款身份、规格和数量一致；当前价格可解释；独立市场基准充分 | 未来才允许使用捡漏标签 | 缺任一条件不得生成 |

**SKU 详情是增强证据，不是官方优惠展示的阻断条件。** 当前 AppKey 的 SKU 详情接口受 API 包限制时，已满足“官方优惠观察”的联盟物料仍可展示；它只失去规格比较、库存核验和捡漏判定能力。

## 3. 价格与优惠条件

1. 默认显示官方返回的联盟推广价 `zk_final_price`，标签为“淘宝联盟官方推广价”。
2. 券后单件试算仅在券金额、门槛、有效期和适用数量都由同一响应解释时显示，必须标为“条件价”，不能写成账户到手价。
3. `final_promotion_price` 只有在当前价格路径可逐项复算时才展示；无法解释的预估金额只留审计字段，不参与展示、排序或结论。
4. 没有有效正数价格的记录必须留在来源审计或被拒收，不能在默认列表显示“金额未提取”或“金额口径待确认”来冒充报价。
5. 每条官方优惠观察必须可回到官方推广入口；不能指向官方商品或推广路径的记录不得升级。

## 4. 捡漏的严格定义

官方推广价只证明官方渠道当前返回了推广报价。要形成捡漏结论，还需要两层独立证据：

- **同款可比**：商品 ID、SKU/规格、数量和计价单位一致，不能只靠标题相似。
- **市场基准**：来自独立可审计商品观察的同款价格序列，排除同店同链接、转载和重复采样；基准样本、来源独立性和新鲜度满足品类配置。

缺任一层时，页面显示“官方优惠观察，尚无同款基准”，而不是捡漏、最低价、利润或账号到手价。个人交易、持仓、出售和收益不属于本平台功能，也不作为判断依据。

## 5. 当前数据流

```text
淘宝联盟官方物料 API
  -> 参数与签名校验
  -> 商品身份和官方入口校验
  -> 价格/优惠路径解释
  -> 原始候选 或 官方优惠观察
  -> 默认列表、详情和来源审计
  -> （将来）SKU 绑定 + 独立市场基准 -> 捡漏判定
```

worker 每分钟检查一次所有到期、已启用的淘宝联盟主题；每个主题按自己的频率独立执行。每轮从第 1 页以 100 条请求官方 API，持续翻页到不足 100 条；若 API 重复整页、官方结果页数已耗尽或达到本地 1000 页安全上限，立即停止并在 `source_scan_runs` 写明原因。官方返回的 `total_results` 仅作为分页上界审计字段；出现短页时，以短页作为“本应用当前实际可取得结果已耗尽”的依据，不能把总数当作可访问商品数。每次扫描的原始数、解析数、优惠数、拒收数和证据回执均可复查。

## 7. 当前验收结论与下一门槛

已验证：纸品主题第 28 次官方同步自动翻到第 9 页后耗尽，返回原始物料 899 条、解析 898 条、带优惠信号 871 条、拒收 1 条。新增主题的真实官方回放分别为：饮用水（399 / 395 / 391 / 4）、大米（199 / 197 / 191 / 2）、面粉（896 / 886 / 793 / 10）、食用油（99 / 92 / 91 / 7）、洗衣液（699 / 689 / 670 / 10）；四个数字依次为原始 / 解析 / 优惠信号 / 拒收。重审后，来源 #44 当前有 911 条 `observed` 官方优惠观察；27 条虽有商品价但无降价、有效券或可解释促销路径，已降为 `conditional` 审计记录，默认列表不可见。分页专项、主题调度专项、自动复审专项、默认列表实测均已通过。

尚未通过：独立同款市场基准、SKU 规格充分覆盖、账户结算价和“已证实捡漏”判定。下一次开发只能围绕这些缺口增加真实证据，不能恢复“SKU 详情受限便隐藏官方优惠”的旧门槛，也不能把历史来源数量当作覆盖能力。

## 8. 文档与变更规则

- 改动产品、来源准入、价格口径或捡漏定义时，先更新本页，再更新对应实现和验收。
- 任何当前结论必须带当日数据回放、测试或数据库快照依据；没有依据时写“未验证”。
- `docs/history/` 的内容不得被链接为当前规则。
- `tests/test_current_product_contract.py` 约束根目录现行文档指向本页，并守住“SKU 详情不阻断官方优惠观察”的不变量。
