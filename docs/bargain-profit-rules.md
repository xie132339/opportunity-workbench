# 捡漏与转售利润：当前规则审计与目标口径

> 2026-10-04 阶段纠正：先补齐来源、商品身份、公开报价、同款行情、转售参考和预计费用，再筛选与预估利润；本人结算、库存及实际交易属于后续执行，不得作为当前采集验收的前提。当前口径以核心台账为准。

> 当前范围补充（2026-10-05）：工作台不再提供用户本人的买入、持仓、出售、退款和实际收益台账。下文“实际收益/交易记录”属于历史规则审计或平台外核算说明，不是本产品功能，不是验收门槛；公开来源的外部成交/回收报价仍是行情证据。


核对日期：2026-10-04。依据：当前 `feature/bootstrap` 源码、无数据库写入的合成反例、正式数据库只读计数。本文区分已经执行的规则与待实现规则；本文更新不代表算法已升级。

## 结论

**目前不满足“自动判断值得买入且能赚钱”的完整要求。** 自动商家公开页历史价格采集与判定已撤下：当前渠道读不到足够、持续、可比的商家商品页标价，它不能承担核心准入或捡漏判断。现有来源报价排序只提供线报声称价位置；自用省钱、已证实捡漏和可靠转售利润仍需可验证的同款价格、优惠条件和费用证据。

当前最多能输出“公开线索”“低于已录入历史样本”“条件价差为正”。不能输出“全网史低”“必买”“买了就赚”或“可重复稳定套利”。22 项工程测试通过证明相应程序行为，不能证明实际商业盈利。

## 2026-10-05：省钱、捡漏与来源低价的可执行区分

以下是目标判定规则；其中只有“来源低价线索”已部分执行，省钱和捡漏结论仍因缺行情数据未能自动判定。

| 结果 | 必须满足的证据与公式 | 缺证据时的展示 |
|---|---|---|
| 来源低价线索 | 原文解析出金额后，在同规格/数量/已提及条件的采集声称价中排序 | 明确写“来源声称价”；不写省钱、捡漏或最低到手价 |
| 自用省钱 | 同一可复用商品身份、选中规格、购买数量、优惠资格与期限；至少两个独立商家当前可执行现金方案；金额都含运费及强制支出。节省金额=次低方案含运费总额−最低方案含运费总额，另显示比例 | 缺任一价格、条件或独立商家来源即“无法判定省钱”；不要求用户先购买或提供个人实付 |
| 商家公开标价历史 | 已撤下，不参与商品准入、排序、通知或捡漏判定 | 不再等待商家网页历史；无可靠同款价格依据时明确显示“无法判断” |
| 自用省钱已证实 | 同一可复用商品身份、选中规格、购买数量、优惠资格与期限；至少两个独立商家当前可执行现金方案；价格都含运费及强制支出。节省金额=次低方案含费总额−最低方案含费总额，另显示比例 | 缺任一价格、条件或独立商家来源即“无法判定省钱”；不要求用户先购买或提供个人实付 |
| 可执行捡漏结论 | 当前可执行含费价格低于有证据的同条件参考价；参考可以是跨商家当前报价或同页历史的实际可得总价。公开标价历史候选只能作为发现信号，不能单独升级为已证实捡漏 | 当前公开标价、历史划线价或单条爆料均不足以给出到手省钱结论 |
| 转售利润候选 | 独立使用保守退出收入减买入总额和全部适用费用；报价/成交类型分开，费用缺项不按零；再检查品类预算与风险策略 | 自用节省和历史低价都不能代替利润测算 |

曾尝试用90天、30个不同观察日和P10计算公开页历史低价候选；该采集和判断代码已撤下。它们不是当前执行规则，亦无真实数据支持，不能作为可用或推荐门槛。未来若引入合法且稳定的同款价格历史，须用真实价格回放重新定标。金额门槛不设成跨品类固定值：界面报告金额和比例，是否值得自用由用户意愿决定；转售的最低净利等使用单独的品类/策略参数。

本次真实反例：#6313 与 #7932 都解析到京东商品ID `10227009872471`，分别是逛丢/GUANGDIU 内容里的4.37元与4.45元声称价，相差8分钱。它们是同一商家商品页的两个聚合线索，不是两个独立商家方案。正式库当时 `public_price_observed=0`、`quotes=0`；因此旧的“可少支出0.08元”表述没有依据。本次代码现把它们保留作线索，但不计为两个可比购买方案；含凑单/积分/返现等未解决优化缺口的条目也不得赢得比价。其余无商品ID的来源价比较仍只称“来源声称价位置”，不作省钱或捡漏判定。

**已撤回的实现（2026-10-05）**：曾尝试从无需登录的商品页 HTML 读取 JSON-LD/Open Graph 公开号，再按近90天、至少30个观察日、P10与中位数计算“历史低价候选”。正式库验收中公开价观测为0；页面大量返回无结构化报价、访问限制或重试。因此撤掉采集器、历史算法、详情展示与后台轮询；不再把无法持续取数的商家页面当作核心依赖。既有 SQLite 观测表/记录不删除。

这套 `historical_low_candidate` 规则已停用。P10/90天/30日没有真实价格样本校准，不能声称是有效的捡漏门槛。核心应落在能够持续采集、按商品与优惠条件规范化的多渠道线索；数据不足时保留为“来源报价线索/无法比较”，不能用商家页面抓取失败补算。

## 一、必须分别回答的四个问题

| 判断 | 合格证据 | 不能代替它的东西 |
|---|---|---|
| 是不是便宜 | 同 SKU、版本、成色、整单数量、质量等级和优惠资格的可比价格；同时考虑当前替代购买渠道 | 划线价、宣传折扣、不同包数的每包价、只采一条爆料 |
| 我能否买到 | 本人账号、地区、指定 SKU 和数量的近期结算报价、运费、优惠实际生效、库存、有效期和限购 | 标题写“新人”“88VIP”、别人付款截图、页面能打开 |
| 能否卖出去 | 可验证的同款已完成交易，或绑定具体货品且仍有效的最终承接报价；数量与预计售出期限 | 卖家挂牌、收藏浏览量、AI 估价、普通回收预估 |
| 值不值得做 | 全部成本后的金额收益、投入回报率、周转时间、可能损失及资金占用均符合品类策略 | 只有卖价减买价为正；只看百分比；把未售库存算利润 |

自用低价与转售盈利分开：自用看真实节省与是否需要；转售必须再证明退出渠道及费用。转售有利润不必然要求突破历史最低，历史最低也不证明能转卖。

## 三、目标利润口径（待实现）

以**一笔完整交易／一批可实际购买并出售的数量**为计算单位，不混用每包、每件、每箱、整单或折合价。

**保守预计净利 = 有依据的可实现卖出收入 − 买入现金支出 − 买入运费 − 卖出运费 − 平台及支付费用 − 包装检测维修费用 − 为本次交易新增的会员等支出 − 适用税费与其他费用 − 持有成本 − 风险预留。**

退出收入尚未扣平台费时在成本项扣；已经扣除时不得重复扣。未到账返现、积分、未来订单券不按现金收入抵减当前买入成本；已在付款价中减掉的优惠不能再减一次。未退保证金计资金占用，确认损失后才计损失。

**投入回报率 = 保守预计净利 ÷ 预计峰值资金占用。** 峰值资金占用包含需先行支付的采购款、费用、保证金，以及未到账返款占用；不能只用“返后价”作分母。这个指标及峰值现金流模型目前未实现。

**已实现净利 = 经到账证据确认的出售收入及其他净入账 − 全部实际支出与实际损失。** 已付费用只扣一次；风险预留只是事前估算，结算时换成实际损失，不能再重复扣。未售库存、挂单价、买家口头意向均不算已赚到钱。

### 建议采用两类候选，而不是一个混合开关

**自用低价候选**：购买资格与库存可执行、同规格同质量可比，含运费现金价低于可取得的同条件基准，且节省金额有实际意义。没有可靠基准时只能叫报价线索；可比样本不足也不强行判为史低。

**转售盈利候选**：购买可执行、货品真伪／成色／数量匹配、退出有依据、成本齐全，再同时满足以下品类参数：最低净利 `P_min`、最低投入回报率 `R_min`、最长周转天数 `T_max`、可承受损失上限 `L_max` 和资金占用上限 `B_max`。史低只作额外标记或排序信号，不强制作为转售必要条件。

这些参数尚未实现，也没有真实交易数据支持统一数值。旧文档的“30 元且 20%”只是未验证的试验建议，**不是当前放行门槛，也不是跨品类盈利标准**。纸品与手机不应共用一个固定绝对利润值。样本、成本或销量证据不足时自动输出具体缺口，不让 AI 编造概率、保底卖价或填 0。

新人优惠只计算合法可用账号的真实资格和剩余限购量；一次可买一件不扩算成十件、一百件的总利润。计划购买量不得超过可买数量、可信承接数量、资金及损失预算支持的数量。

## 四、纸品例子：便宜与赚钱分开

以下为算术示例，不是当前在售价格或市场成交证据。假设同规格纸原本需要花 20 元购买，现在本人含运费付 12.32 元，自用节省 7.68 元。但若转卖只能收 18 元，卖出运费 6 元、包装 1 元，即使其他费用暂设为已确认的 0，净利也是 **18 − 12.32 − 6 − 1 = −1.32 元**。若再有平台费或退货损失，会更低。

因此“纸很便宜”可以是自用低价，却不能推出“买来转卖有利可图”。不能用抽纸的每包折合价格套到整提收入，也不能用已售几十单的页面文案当成当前承接订单。

## 五、自动化补齐的验收标准

系统按“候选采集 → 精确规格和整单数量归一 → 本人账号可执行报价／库存 → 历史基准或退出成交 → 费用及风险 → 品类门槛 → 有效期内复查 → 结果提醒 → 到账复盘”自动处理。账号授权、连接配置是一次性的接入条件，不能把每条数据的核验工作转交给用户。

完成标准：同一真实商品从发现到账号报价、退出依据和全部费用均可追溯；价格、资格、库存或费用变化会撤销候选；有样本外历史回放和实际小额交易的到账证据后，才评估误报率、净收益与周转。回放及一次盈利也不证明长期稳定盈利。买卖动作仍独立于信息判断，不自动获得下单授权。

公开回收预估不得冒充最终退出价：[京东 3C 以旧换新官方协议](https://help.jd.com/user/issue/389-4626.html)说明最终成交价受质检和行情等影响，可能与预估不同（2026-10-04 核对）。具体物品能否在买入前取得足够可靠的承接价，需要该渠道自身证据，不能假设所有商品都能回收。
