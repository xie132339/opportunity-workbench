## 不作为默认优惠数据源的内容

第三方优惠聚合帖、转载 RSS、商城目录、无法直达商品的跳转页、无法解释价格的页面和未知来源，均不能写入默认优惠列表。它们若保留，只能用于人工发现或来源审计，不能成为价格或捡漏证据。

## 接入新渠道的硬条件

1. 有合法、可持续的第一方或授权数据入口。
2. 能获得商品身份、直达入口、价格、优惠条件和采集时间。
3. 能保存原始响应并完成重复来源隔离。
4. 在隔离回放中证明它不会把原价目录或转载文案写入默认列表。

满足后才可新增连接器；渠道数量不是接入依据。历史渠道调研在 [history/](history/README.md)，不代表当前启用状态。
