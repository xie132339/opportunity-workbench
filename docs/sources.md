## 在工作台配置渠道

打开 [渠道管理](http://127.0.0.1:5002/sources) → “新增来源”：

1. **公开网页解析**：填平台、入口名、类别、公开 HTTPS 列表页、检查间隔，选择与域名一致的已适配解析规则。比如苏宁 `https://www.suning.com/` 选“苏宁易购”；点“新增来源”后在卡片上点“现在检查”。只有显示“正常”且已保存条目大于 0，才算本次解析成功。已存在的相同入口不能重复添加。
2. **RSS 订阅**：填真实 RSS／Atom 的 HTTPS 地址；先检查是否提取到带原始链接的条目。当前尚无经实测可用的具体 RSS 源。
3. **网页变化监控**：需要本机 changedetection 服务和 API 凭据；此方式只记录整个页面变化，不拆分商品。适合盯单个商品的补货或公告，不宜把商城首页变化当成“发现了商品”。
4. **人工录入**：动态、登录限制或尚无解析器的平台，在机会中心填写具体商品链接。新增一个“人工”渠道并不等于该平台已有自动采集。

公开网页解析仍只存标题、商品链接和发现时间；真实付款价、会员资格、库存、同款历史低价和转售成交证据须另行核实。
