# 实施计划：淘宝官方优惠与可证据化捡漏

## 当前目标

以 [当前产品契约](../../docs/current-product-contract.md) 为唯一规则，把淘宝联盟第一方优惠物料稳定地发现、解释和展示；只有同款市场基准完整后才生成捡漏结论。

## 已完成并验证

- [x] 官方物料 API `taobao.tbk.dg.material.optional.upgrade` 实测可返回优惠物料。
- [x] 官方推广价进入默认列表，显示为“淘宝联盟官方推广价 / 官方优惠观察”。
- [x] SKU 详情受限不再阻断已合格官方优惠观察。
- [x] 无法解释的 `final_promotion_price` 不展示、不排序、不参与结论。
- [x] 当前产品、来源、需求、环境和验收文档已收敛到单一产品契约；历史材料已隔离。

## 当前证据

- 2026-10-11 第 28 次真实同步：每页 100 条，自动翻到第 9 页，原始 899、解析 898、优惠信号 871、拒收 1，停止原因为 `page_exhausted`。
- 本机数据库快照：来源 #44 已启用且健康、60 分钟间隔；重审后 911 条 `observed` 官方优惠观察，27 条无优惠信号商品价已降为 `conditional` 审计记录。
- 回归：分页和自动复审专项已通过；全量 `unittest discover -s tests` 共 289 项通过；网页服务和定时 worker 已重启。

## 下一开发步骤

1. 设计并接入独立同款市场基准观察，确保来源独立、规格/数量可比并有新鲜度。
2. 仅对已绑定 SKU 的记录计算同款基准；标题相似只能召回，不能作为同款确认。
3. 用真实观察回放基准统计、异常值隔离和“尚无同款基准”降级。
4. 达到产品契约的全部捡漏前置后，再启用“已证实捡漏”标签与排序。

## 不允许回退

- 不恢复“SKU 详情受限就隐藏官方优惠观察”的条件。
- 不把推广价、券试算或无法解释预估价叫作账号到手价。
- 不把转载、目录或历史日志写入默认优惠列表。
- 不从 `.agent/execplans/history/` 推导当前状态；需要旧事实时必须重新验证。
