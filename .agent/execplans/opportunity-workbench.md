# 实施多平台机会工作台

This ExecPlan is a living document maintained according to `~/.codex/PLANS.md`.

## Purpose and observable outcome

在本机运行中文机会工作台，接入多个中国市场公开来源，展示来源、时效与错误；支持筛选、人工行情和成本核算、买入/库存/出售/退款记录。每阶段保存环境命令与结果并同步 Obsidian。完整首版是 M1—M5，监控启动仅代表部分完成。

## Scope, constraints, and assumptions

用户于 2026-10-02 明确授权开始所有阶段并沉淀环境操作，并随后明确要求开发阶段从源码启动，所需场景完成后再制作 Docker 部署。个人本地使用，固定版本、回环监听，不购买云服务、不实际交易、不外发消息。保留无关仓库。当前开发分支 feature/bootstrap。执行真实启动与功能验收，不额外添加测试框架。国内入口低频实测，登录受限时据实标记，不绕过验证。

## Surprises and discoveries

- 项目父目录与 Obsidian 均非 Git 仓库，本项目为新建独立仓库。
- 本机系统 Python 较旧，优先使用隔离环境。
- 长中文 shell 输入发生编码损坏，后续内容先写 UTF-8 暂存文件，再用短 ASCII 脚本安装与逐字核对。
- 中断后的现场检查：changedetection 镜像没有留在本机，也没有本项目容器；既有的 Dependency-Track 容器属于其他工作，保持原状。
- SMZDM 初版 HTML 解析将价格标签误当标题；已按链接选较完整标题，并保留但默认忽略 20 条价格标签或非可投标公告记录。中国政府采购网只取公开招标，不将中标结果和更正公告当新商机。
- 义乌购库存尾货页面 HTTP 200，但服务器返回的 HTML 暂无可提取条目；孔夫子首页多为目录、推荐，不能直接当在售二手线索。两者保持候选/人工，不虚报自动支持。
