## Surprises and discoveries

- 项目父目录与 Obsidian 均非 Git 仓库，本项目为新建独立仓库。
- 本机系统 Python 较旧，优先使用隔离环境。
- 长中文 shell 输入发生编码损坏，后续内容先写 UTF-8 暂存文件，再用短 ASCII 脚本安装与逐字核对。
- 中断后的现场检查：changedetection 镜像没有留在本机，也没有本项目容器；既有的 Dependency-Track 容器属于其他工作，保持原状。
- SMZDM 初版 HTML 解析将价格标签误当标题；已按链接选较完整标题，并保留但默认忽略 20 条价格标签或非可投标公告记录。中国政府采购网只取公开招标，不将中标结果和更正公告当新商机。
- 页面视觉复查发现 UTC 时间不适合中国用户，已在 UI 转为北京时间；通用首页变化监控虽有实际快照，但不等于商品线索，演示任务已暂停且该条机会被忽略。
- 义乌购库存尾货页面 HTTP 200，但服务器返回的 HTML 暂无可提取条目，保持候选。孔夫子旧书网后来已从首页提取 27 条具体在售链接；链接仍不证明商品在售、成交或有转卖利润。
